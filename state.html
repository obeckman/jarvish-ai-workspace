Signal

Risk

API behavior, streaming, session storage, and agent mapping can become hard to change without regressions.

Resolver Refactor Plan implemented

Target

Make resolvers thin GraphQL adapters

Move DB queries, agent stream mapping, message conversion, summary generation, and mutations out of src/Backend/graphql/resolvers.ts.

Shape

New folders under src/Backend/graphql/

Signal

Current work touches parser.ts, useJarvishChat.ts, block schemas, and renderer logs.

Risk

One malformed stream payload can produce wrong block types, noisy logs, recursion issues, or unstable message IDs.

First Refactor

Create one message-normalization pipeline: raw event → parsed blocks → stable message model → renderer.
