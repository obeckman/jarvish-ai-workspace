# Product Definition: Jarvish Agent

Jarvish is a personal research agent platform. It provides a conversational interface for users to conduct deep research, leveraging long-term memory and background processing tools.

## Key Features
- **Conversational AI**: Interactive chat with an agent (Jarvish).
- **Session Management**: Persistent research sessions with history and summaries.
- **Long-term Memory**: Integration with Weaviate vector database for fact extraction and retrieval.
- **Background Processing**: Status logging and stage-based orchestration of research tasks.
- **File Attachments**: Support for uploading documents (PDFs, etc.) for analysis.

## Target Audience
- Developers and researchers looking for a custom, memory-augmented AI assistant.
