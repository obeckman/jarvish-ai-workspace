# Tech Stack: my-react-playground

## Frontend
- **Framework**: React 19.2
- **Build Tool**: Vite 7.2
- **Language**: TypeScript 6.0
- **State Management**: React useReducer + Context API
- **Styling**: Vanilla CSS, SCSS Modules
- **GraphQL Client**: fetch() (raw string queries)

## Backend
- **Server**: Express 5.2
- **GraphQL**: GraphQL Yoga 5.21
- **Database**: Drizzle ORM (SQLite / better-sqlite3)
- **Vector DB**: Weaviate Client 3.12
- **AI Framework**: LangChain 1.3, Google Generative AI

## Tooling
- **Linting**: ESLint 9
- **Formatting**: Prettier
- **Environment**: Node.js (v24+)
- **Package Manager**: npm
